=========================================================
基于 SpringBoot 的宿舍报修管理系统 - 程序运行说明
=========================================================

一、开发环境与平台要求
---------------------------------------------------------
1. 操作系统：Windows 10 / Windows 11 / macOS
2. 后端运行环境：JDK 17
3. 数据库环境：MySQL 8.x
4. 缓存环境：Redis 7.x（必须启动，用于存储登录验证码）
5. 前端运行环境：Node.js 18+ 
6. 项目构建工具：Maven 3.8+、npm


二、使用的主要技术
---------------------------------------------------------
1. 后端技术：SpringBoot 3、MyBatis-Plus、JWT鉴权、Spring AOP、WebSocket、Apache POI
2. 前端技术：Vue 3、TypeScript、Vite、Axios
3. 扩展技术：DeepSeek大模型API（用于智能辅助分类与派单推荐）

四、项目启动与运行步骤
---------------------------------------------------------
【第 1 步：初始化数据库】
1. 打开您的 MySQL 数据库管理工具（如 Navicat），创建一个名为 `dormitory_repair` 的数据库（字符集推荐 utf8mb4）。
2. 依次运行后端项目 `sql` 文件夹下的数据库脚本：
   - 首先运行：sql/dormitory_repair_init.sql
   - 然后运行：sql/01_add_repairer_role.sql
   - 最后运行：sql/02_add_operation_log.sql

【第 2 步：启动 Redis 服务】
1. 请确保本地已安装并启动 Redis 服务。
2. 默认配置为：127.0.0.1，端口 6379，无密码。（如您本机的 Redis 有密码，请在后端的 application.yml 中对应修改）。

【第 3 步：配置并启动后端 (dormitory-repair-backend)】
1. 使用 IntelliJ IDEA 打开 `dormitory-repair-backend` 文件夹。
2. 等待 Maven 自动下载依赖。
3. 打开 `src/main/resources/application.yml`，根据您本机的实际情况修改 MySQL 数据库密码（默认为 root-123456，请务必修改为您自己的密码）。
4. 找到 `DormitoryRepairApplication.java` 启动类，右键点击 Run 运行。
5. 后端默认启动在 8080 端口。

【第 4 步：启动前端 (dormitory-repair-frontend)】
1. 打开命令行终端（Terminal），进入 `dormitory-repair-frontend` 文件夹。
2. 运行 `npm install` 下载前端依赖。
3. 运行 `npm run dev` 启动前端开发服务器。
4. 控制台将输出一个本地访问地址（通常为 http://localhost:5173/），在浏览器中打开此地址即可进入系统登录页面。
五、特别说明（AI 功能测试）
---------------------------------------------------------
1. 本系统在“学生提交报修”和“管理员派单”环节接入了 AI 智能大模型功能。
2. 该功能的 API Key 已经配置在后端的 `application.yml` 文件中。
3. 如果老师在测试时由于网络原因导致 AI 请求超时或失败，系统会自动降级处理，不会影响正常的业务流转，依然可以手动完成报修和派单测试。
六、高级用法：Docker 一键部署（可选）
---------------------------------------------------------
为了极大简化部署流程，本项目已完整配置了 Docker 容器化环境。如果您的电脑已安装 Docker Desktop，可跳过第四步繁琐的本地环境配置，直接一键启动整个系统：

1. 打开命令行终端（Terminal/PowerShell），进入项目根目录。
2. 运行一键启动命令：
   docker-compose up -d --build
3. Docker 将自动为您拉取 MySQL 8.0、Redis 7，并自动初始化数据库脚本（包含测试数据），同时打包运行前后端代码。
4. 等待控制台提示所有容器 Started 完毕（约 10-20 秒）后，打开浏览器访问：
   http://localhost/
   即可直接进入系统！
   （注：为避免与宿主机原生 MySQL 冲突，Docker 暴露的数据库端口已自动修改为 3307）
